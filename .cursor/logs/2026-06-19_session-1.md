### [backfilled] CONVO — ⋁_P vs ⋁_Q with domain Q ⊆ P

Core encoding: `Q : Set P`, `S : Set Q`, ambient sup `IsLUB (Subtype.val '' S) p`, sub-poset sup `IsLUB S ⟨p, hpQ⟩`. Connecting lemma (Lemma 2.28 join): if ambient sup exists and `p ∈ Q`, then `⟨p, hpQ⟩` is sup in `Q`. Meet version dual with `IsGLB`.

---

### [backfilled] CONVO — Subtype.val explained

`Subtype.val` strips the membership proof from `⟨p, hpQ⟩ : Q`, returning `p : P`. `Subtype.val '' S` reindexes `S : Set Q` as a subset of `P` for ambient-order reasoning.

---

### [backfilled] CONVO — ⟨p, hpQ⟩ and existential vs named witnesses

`⟨p, hpQ⟩` packages `p : P` with `hpQ : p ∈ Q` as an element of sub-poset `Q`. Prefer named `(p : P) (hp : ...)` in main lemmas; existential wrappers optional. Do not put `(q : Q)` in assumptions when proving existence of sup in `Q`.
